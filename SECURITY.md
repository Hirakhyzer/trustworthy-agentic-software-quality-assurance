# Security Policy

## Research prototype

This repository is an academic prototype and should not be treated as a production release-approval or security-control system.

## Reporting a security concern

Please avoid publishing exploit details, credentials, personal data, or confidential source material in public issues. Report security concerns privately to the repository maintainer through an appropriate GitHub contact channel.

## Scope

Relevant reports include:

- unintended execution or modification of external systems;
- unsafe handling of repository data;
- dependency vulnerabilities introduced by the project;
- mechanisms that could bypass configured human approval gates;
- accidental exposure of sensitive experiment data.

Quality findings produced by this prototype are research outputs and must not be interpreted as security certification.
